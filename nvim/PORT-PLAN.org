#+TITLE: Rybalt Neovim Setup & Port Plan
#+AUTHOR: Ryan Baltazar

* Overview

Migration target: Neovim (via Neovide GUI on macOS, LazyVim bootstrap) as
the "text editor" slot in a multi-tool workflow. Rider stays for serious
Unity C#/C++ engineering. Emacs remains installed as a fallback while
this migration stabilizes, and for org-mode (which has no real Neovim
equivalent).

*Primary workflow to preserve:* inline comments in prettified markdown
as agent instructions. Requires readable-grade markdown rendering
(variable-pitch prose, distinct code blocks, centered reading column)
and the ability to easily find markdown files that live in gitignored
=.claude/= dirs across a multi-repo umbrella workspace.

Each umbrella workspace (e.g. =A_Feature_In_Development/=) needs two
marker files at its root:

** =.projectile= (empty marker file)

Reused from Emacs. Defines the umbrella boundary for workspace-scoped

** =lua/rb/workspace.lua= — root detection and file-finding

Walks up from Neovim's CWD (not buffer realpath) looking for
=.projectile= marker; falls back to nearest =.git=; falls back to cwd.
The cwd-based approach is symlink-proof: opening a file through the
=docs/= symlink keeps the umbrella as workspace, even though the file's
realpath is outside the umbrella.

#+begin_src lua
local M = {}

local function find_marker(start, marker)
  local dir = start
  while dir ~= "/" do
    if vim.uv.fs_stat(dir .. "/" .. marker) then return dir end
    dir = vim.fn.fnamemodify(dir, ":h")
  end
  return nil
end

function M.workspace_root()
  local cwd = vim.fn.getcwd()
  return find_marker(cwd, ".projectile")
      or find_marker(cwd, ".git")
      or cwd
end

function M.repo_root()
  local buf_dir = vim.fn.expand("%:p:h")  -- symlink-preserving
  return find_marker(buf_dir, ".git") or M.workspace_root()
end

-- fd flag sets
local FD_WORKSPACE = { "--type", "file", "--hidden", "--follow",
                       "--exclude", ".git" }
local FD_ALL       = { "--type", "file", "--hidden", "--follow",
                       "--no-ignore", "--exclude", ".git" }

function M.find_file()
  require("snacks.picker").files({
    cwd = M.workspace_root(),
    cmd = "fd",
    args = FD_WORKSPACE,
  })
end

function M.find_all()
  require("snacks.picker").files({
    cwd = M.workspace_root(),
    cmd = "fd",
    args = FD_ALL,
  })
end

function M.grep()
  require("snacks.picker").grep({ cwd = M.workspace_root() })
end

function M.init(dir)
  dir = dir or vim.fn.input("Workspace root: ", vim.fn.getcwd(), "dir")
  if dir == "" then return end
  dir = vim.fn.fnamemodify(dir, ":p"):gsub("/$", "")
  local projectile = dir .. "/.projectile"
  local fdignore   = dir .. "/.fdignore"
  if not vim.uv.fs_stat(projectile) then
    vim.fn.writefile({}, projectile)
  end
  if not vim.uv.fs_stat(fdignore) then
    vim.fn.writefile({
      "# Unity noise",
      "Library/", "Temp/", "obj/", "Build/", "Builds/",
      "Logs/", "UserSettings/",
      "*.csproj", "*.sln",
      "",
      "# Marker/config files",
      ".projectile", ".fdignore",
      "",
      "# Re-include gitignored-but-useful",
      "!.claude/", "!.claude/**",
    }, fdignore)
  end
  vim.cmd.cd(dir)
  vim.notify("Workspace: " .. dir)
end

return M
#+end_src

** =lua/rb/multi-repo.lua= — pick-a-repo Neogit launcher

Replaces =rb-magit-status= (=SPC g g=). Discovers git repos immediately
under the workspace root, presents an MRU-sorted picker, opens Neogit
on the selection.

** =lua/rb/changed-files.lua= — staged/unstaged/untracked picker

Replaces =rb-changed-files= (=SPC g d=). A picker sourced from
=git diff --name-only --cached= + =git diff --name-only= +
=git ls-files --others --exclude-standard=, with a column of
=+X -Y= numstat annotations.

** =lua/rb/homepage/init.lua= — async PR dashboard

Custom plugin showing GitHub PRs authored by, assigned to, or
review-requested from the authenticated user. Fetches via =gh= CLI
using GraphQL (=vim.system= callback + =vim.schedule= for Neovim API
access). Multi-host auth discovery (parses =gh auth status= output).
In-flight coalescing: extraneous opens during a pending fetch are
ignored if the buffer is still visible. Status tokens:
=[DRAFT]/[APPROVED]/[CHANGES]/[AWAITING]= with unresolved thread counts.

* Prose prettification

Replaces =rb-prose-mode= (olivetti + mixed-pitch + org-modern glyphs +
visual-line-mode). The Neovim equivalent stacks:

- =render-markdown.nvim= — code block backgrounds, list bullets (●◦▸),
  checkboxes (☐☑). Headings disabled (=heading.enabled = false=) so raw
  =#/==/=### are preserved rather than replaced with glyphs.
  =render_modes= excludes ='i'= so insert mode shows raw markdown.
  =anti_conceal.enabled = false= to avoid cursor-line pop-in.
- =zen-mode.nvim= — centered column (olivetti replacement); hides side
  windows during focus so it doesn't fight the file tree. Bound to =<leader>uz=.
  (no-neck-pain.nvim was tried first but moved the file tree.)
- Neovide per-highlight-group =guifont= — variable-pitch prose, fixed-pitch code

  *Known limitation*: =nvim_set_hl= does not accept a ="font"= key; the API
  rejected it at runtime. Per-highlight-group font switching is a Neovide
  extension but must be done via =GuiFont= commands or =highlight-gui=, not
  the standard Lua =nvim_set_hl= API. This remains unresolved — iA Writer Quattro
  is not currently active. The =font= lines in the autocmd have been removed.

*** Solution discovery (validated against HandExtensibility)

=broad_search= walks UP from the =.cs= file looking for =.sln= files.
This works when editing inside a test project (the =.sln= is an ancestor),
but *fails for package source*: package repos (=com.unity.xr.hands/=,
=xr.sdk.openxr/=, etc.) are siblings of =TestProjects/=, not children.
Walking up from package source never encounters a =.sln=.

Additionally, there are 16+ =.sln= files on disk including CI recipe
solutions, native plugin build solutions, vendored Android NDK solutions,
and Library/PackageCache solutions. Only the test project =.sln= files
(=HandExtensibility2.sln=, =AI_UserResearch_Apr7.sln=, etc.) are correct
targets — the generated =.csproj= files in those projects reference the
package source via absolute =<Compile Include>= paths.

*Solution*: custom =choose_target= + =ignore_target= callbacks in
=csharp.lua= that:

1. =ignore_target=: filters out noise =.sln= files matching =Tools/CI/=,
   =artifacts/=, =Library/=, =NativePlugin~/=, =Submodules~/=,
   =build.gen.sln=, and =*-ReadOnly/= paths.

2. =choose_target=: after filtering, uses the session override
   (=vim.g.rb_roslyn_workspace=, set via =:RoslynWorkspace= picker) if
   available; otherwise auto-selects if only one target remains, or
   prompts if multiple. For the package source case (zero targets from
   =broad_search=), scans =TestProjects/= under the workspace root
   (=.projectile= marker) for =.sln= files.

3. =:RoslynWorkspace= command (=<leader>cs=): interactive picker listing
   discovered =.sln= files under =TestProjects/=; stores the selection
   in the session variable and restarts the LSP client.

*** .sln / .csproj generation

Roslyn reads Unity-generated =.sln=/.csproj= files — it cannot create
them. Workflow:

1. *Rider or Unity Editor* generates files initially (Rider auto-regenerates
   via the JetBrains Rider Editor package; Unity: Edit → Preferences →
   External Tools → Regenerate Project Files).
2. Regenerate when =.asmdef= files change or packages are added.
3. Staleness signal: go-to-definition can't find a newly added type, or
   =UnityEngine= namespace errors appear. Regenerate, roslyn picks up
   changes automatically.

Batch-mode regeneration (no UI):
#+begin_src shell
/path/to/Unity -batchmode -nographics -logFile - \
  -executeMethod UnityEditor.SyncVS.SyncSolution \
  -projectPath /path/to/project -quit
#+end_src
