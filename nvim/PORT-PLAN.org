#+TITLE: Rybalt Neovim Setup & Port Plan
#+AUTHOR: Ryan Baltazar

* Overview

Migration target: Neovim (via Neovide GUI on macOS, LazyVim bootstrap) as
the "text editor" slot in a multi-tool workflow. Rider stays for serious
Unity C#/C++ engineering. Emacs remains installed as a fallback while
this migration stabilizes, and for org-mode (which has no real Neovim
equivalent).

*Primary workflow to preserve:* inline comments in prettified markdown
as agent instructions. Requires readable-grade markdown rendering
(variable-pitch prose, distinct code blocks, centered reading column)
and the ability to easily find markdown files that live in gitignored
=.claude/= dirs across a multi-repo umbrella workspace.

* Per-umbrella setup

Each umbrella workspace (e.g. =A_Feature_In_Development/=) needs two
marker files at its root:

** =.projectile= (empty marker file)

Reused from Emacs. Defines the umbrella boundary for workspace-scoped
commands. Kept as =.projectile= (rather than introducing a new marker)
so existing umbrellas Just Work, and so Emacs fallback still recognizes
the workspace.

** =.fdignore=

Controls what fd finds under =SPC w f= (workspace fuzzy-find).
Overrides sub-repo =.gitignore= where needed.

#+begin_src gitignore
# Unity noise — catches test projects that aren't git-tracked
Library/
Temp/
obj/
Build/
Builds/
Logs/
UserSettings/
*.csproj
*.sln

# Marker/config files that are noise in the picker
.projectile
.fdignore

# Re-include gitignored-but-useful (.claude dirs hold agent markdown)
!.claude/
!.claude/**
#+end_src

The =!.claude/= pair overrides a sub-repo =.gitignore= that excludes
=.claude/=, so markdown agent instructions surface in =SPC w f=.
Verified empirically; see the fd-design memory for details.

A =:WorkspaceInit= Lua command (below) creates both files.

* Custom Lua modules

Ported from Emacs, preserving behavior. Each is a small self-contained

** =lua/rb/workspace.lua= — root detection and file-finding

Walks up from Neovim's CWD (not buffer realpath) looking for
=.projectile= marker; falls back to nearest =.git=; falls back to cwd.
The cwd-based approach is symlink-proof: opening a file through the
=docs/= symlink keeps the umbrella as workspace, even though the file's
realpath is outside the umbrella.

#+begin_src lua
local M = {}

local function find_marker(start, marker)
  local dir = start
  while dir ~= "/" do
    if vim.uv.fs_stat(dir .. "/" .. marker) then return dir end
    dir = vim.fn.fnamemodify(dir, ":h")
  end
  return nil
end

function M.workspace_root()
  local cwd = vim.fn.getcwd()
  return find_marker(cwd, ".projectile")
      or find_marker(cwd, ".git")
      or cwd
end

function M.repo_root()
  local buf_dir = vim.fn.expand("%:p:h")  -- symlink-preserving
  return find_marker(buf_dir, ".git") or M.workspace_root()
end

-- fd flag sets
local FD_WORKSPACE = { "--type", "file", "--hidden", "--follow",
                       "--exclude", ".git" }
local FD_ALL       = { "--type", "file", "--hidden", "--follow",
                       "--no-ignore", "--exclude", ".git" }

function M.find_file()
  require("snacks.picker").files({
    cwd = M.workspace_root(),
    cmd = "fd",
    args = FD_WORKSPACE,
  })
end

function M.find_all()
  require("snacks.picker").files({
    cwd = M.workspace_root(),
    cmd = "fd",
    args = FD_ALL,
  })
end

function M.grep()
  require("snacks.picker").grep({ cwd = M.workspace_root() })
end

function M.init(dir)
  dir = dir or vim.fn.input("Workspace root: ", vim.fn.getcwd(), "dir")
  if dir == "" then return end
  dir = vim.fn.fnamemodify(dir, ":p"):gsub("/$", "")
  local projectile = dir .. "/.projectile"
  local fdignore   = dir .. "/.fdignore"
  if not vim.uv.fs_stat(projectile) then
    vim.fn.writefile({}, projectile)
  end
  if not vim.uv.fs_stat(fdignore) then
    vim.fn.writefile({
      "# Unity noise",
      "Library/", "Temp/", "obj/", "Build/", "Builds/",
      "Logs/", "UserSettings/",
      "*.csproj", "*.sln",
      "",
      "# Marker/config files",
      ".projectile", ".fdignore",
      "",
      "# Re-include gitignored-but-useful",
      "!.claude/", "!.claude/**",
    }, fdignore)
  end
  vim.cmd.cd(dir)
  vim.notify("Workspace: " .. dir)
end

return M
#+end_src

** =lua/rb/multi-repo.lua= — pick-a-repo Neogit launcher

Replaces =rb-magit-status= (=SPC g g=). Discovers git repos immediately
under the workspace root, presents an MRU-sorted picker, opens Neogit
on the selection.

** =lua/rb/changed-files.lua= — staged/unstaged/untracked picker

Replaces =rb-changed-files= (=SPC g d=). A picker sourced from
=git diff --name-only --cached= + =git diff --name-only= +
=git ls-files --others --exclude-standard=, with a column of
=+X -Y= numstat annotations.

* Prose prettification

Replaces =rb-prose-mode= (olivetti + mixed-pitch + org-modern glyphs +
visual-line-mode). The Neovim equivalent stacks:

- =render-markdown.nvim= — heading glyphs/sizes, code block backgrounds,

** Variable-pitch prose highlight overrides

Neovide supports per-highlight-group font overrides. Apply iA Writer
Quattro to prose faces; keep FiraMono on code:

#+begin_src lua
-- Markdown-mode autocmd: activate prose treatment
vim.api.nvim_create_autocmd("FileType", {
  pattern = { "markdown", "text" },
  callback = function()
    vim.opt_local.wrap = true
    vim.opt_local.linebreak = true
    vim.opt_local.breakindent = true
    vim.cmd("NoNeckPain")

    -- Scale headings; apply iA Writer Quattro to prose
    local prose_font = "iA Writer Quattro S:h14"
    for _, group in ipairs({
      "RenderMarkdownH1", "RenderMarkdownH2", "RenderMarkdownH3",
      "RenderMarkdownH4", "@markup.heading",
      "Normal", "@text", "@markup",
    }) do
      vim.api.nvim_set_hl(0, group, { font = prose_font })
    end
    -- Keep code blocks in mono
    vim.api.nvim_set_hl(0, "@markup.raw", { font = "FiraMono Nerd Font:h14" })
    vim.api.nvim_set_hl(0, "@markup.raw.block", { font = "FiraMono Nerd Font:h14" })
  end,
})
#+end_src

*** Sign-off

- [ ] Cursor entry into a rendered line reveals the raw markdown (for editing)

** Phase 4: Workspace root detection and file-finding

Neovim's CWD concept makes this noticeably less painful than the Emacs
equivalent. In Emacs, =default-directory= follows the current buffer,
which means "workspace root" has to be recomputed for every buffer and
tends to drift unpredictably (especially through symlinks). In Neovim,
CWD is process-wide and stable; setting =noautochdir= pins it at launch
and root detection becomes a one-shot walk from CWD. If LazyVim's
default picker scoping (git root) is close enough, this phase might be
reduced to just wiring =SPC w f= / =SPC w F= overrides for the
umbrella-wide case.
